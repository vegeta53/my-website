O.A.S.I.S.

Oncology Assessment & Screening Information System

SIH 2026 National Portal Nominee
The Core Problem

Cancer-screening pipelines require clear prioritization of referral urgency without obscuring clinical uncertainty. O.A.S.I.S. delivers an explainable clinician-facing decision-support prototype covering oral, breast, and cervical screening pathways.

Safety Rules & Explainability

Maintains the Screening Priority Index distinct from cancer probability metrics. Strict logic prevents low statistical model scores from overriding symptomatic red flags or abnormal physical findings.

Technical Architecture & Delivery
  • Modern, reactive frontend built with Next.js and TypeScript for rapid, intuitive clinical intakes.
  • Robust backend powered by FastAPI and Pydantic validating data contracts and ensuring strict typing.
  • Persistent assessment history and structured audit logging via SQLModel and SQLite.
  • Machine learning models implemented with scikit-learn strictly as optional explanatory signals, never black-box autonomous arbiters.
